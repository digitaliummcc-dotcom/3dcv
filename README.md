# 3DCV — Interactive 3D CV

Personal portfolio site with an interactive 3D force-directed graph and clustered view, built with Next.js 15, React, and [react-force-graph-3d](https://github.com/vasturiano/react-force-graph-3d) (Three.js).

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm start` | Serve production build |

## Tech

- **Framework**: Next.js 15 (App Router)
- **3D**: react-force-graph-3d + Three.js
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
